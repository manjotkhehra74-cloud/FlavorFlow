# Windows App handoff

This folder contains selected **concept previews** and an adjustment API-contract note, not a standalone runnable app. The main repository includes Windows-specific layouts under `lib/`. The Add/Edit User desktop form, Audit Trail inspector and product-only pending Approval register are now implemented under `lib/features/` and copied here under `lib/` for handoff. Notifications already has a native Windows register under `lib/features/notifications/` and is also copied here. The selected Offline Entries desktop summary, 2FA setup dialog and Daily Labour Entry desktop form are implemented in `lib/features/sync/` and `lib/features/settings/` and copied here. Other selected concepts have **not** all been implemented. Selection approves visual direction, not backend capability or release.

Selected concepts under `preview/`: revised stock-adjustment form, approvals register, approval history, reports library, productivity, daily labour, labour analysis, users & roles, add/edit user, audit trail, notifications, offline entries, 2FA setup, and daily labour entry. Preview rows and values are illustrative, not company defaults.

`ADJUSTMENT_MATERIAL_API_CONTRACT.md` documents blocked server work for material adjustments. Never submit a material ID as `productId` or bypass approval. Labour analysis in the current client contains customer-specific vinegar rules; do not promote those to universal defaults. The separate Truck Loading Calculator has been removed; dispatch entry still calculates weights. No deployment is implied by these previews.
